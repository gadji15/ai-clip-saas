# YouTok Web (Next.js)

This folder contains the standalone Next.js frontend for YouTok.

## Dev

From `apps/web`:

```bash
npm install
npm run dev
```

Then open: http://localhost:3000

## i18n

- Supported locales: `fr`, `en`
- Locale is stored in `youtok_locale` cookie.
- URLs are currently locale-prefixed: `/<locale>/...`.
